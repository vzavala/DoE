## Design of Experiments

*From Data to Models to Decisions*

Slides and Python notebooks of the Experimental Design Short Course by Victor M. Zavala (University of Wisconsin-Madison). This material supports the book **"Statistics for Chemical Engineers: From Data to Models to Decisions"** by Zavala, V. M. (2025), Cambridge University Press,©, [Official Cambridge Website](https://www.cambridge.org/highereducation/books/statistics-for-chemical-engineers/A8DB49C10B02BADA637D13FC02CD62A7#overview)

- **Slides Folder**: Contains the slides, and 4-up handouts in `Slides/handouts` (`*_4up.pdf`, four slides per page). Slides link to the notebooks.

- **Python Folder**: Contains Python notebooks (and data) for the examples in the slides. They open in Google Colab.

- **DoE Lab**: Interactive page to try the techniques, at [vzavala.github.io/DoE](https://vzavala.github.io/DoE/) (source in the `gh-pages` branch).

You can find *more information* about the book at [Author Website](https://zavalab.engr.wisc.edu/publications/statsbook)
